# Generador de Certificados - Señorita Carnaval 2026

Sitio web simple para crear diplomas escolares coloridos con vista previa en tiempo real.

## Incluye

- Campos editables para:
  - nombre de la estudiante
  - grado o categoría
  - texto de reconocimiento
  - nombre del colegio y evento
  - firmas y fecha
- Carga de logo del establecimiento
- Temas de color creativos
- Botón para **imprimir o guardar en PDF**

## Uso

1. Abre `index.html` en tu navegador.
2. Completa los datos del certificado.
3. Sube el logo del colegio.
4. Haz clic en **Imprimir / Guardar PDF**.
