# Generador de Certificados - Señorita Carnaval 2026

Sitio web simple para crear diplomas escolares coloridos con vista previa en tiempo real.

## Incluye

- Campos editables para:
  - nombre de la estudiante
  - categoría oficial (A, B, C, D o personalizada)
  - grados participantes
  - temática de vestuario
  - texto de reconocimiento
  - nombre del colegio y evento
  - firmas y fecha
- Carga de logo del establecimiento
- Plantillas visuales inspiradas en estilos de carnaval:
  - Carnaval Clásico
  - Infantil Alegre
  - Comparsa Elegante
  - Máscaras Vibrantes
- Opciones para decidir si se incluye o no en el diploma:
  - categoría
  - grados
  - temática
  - reconocimiento
  - logo
  - fecha y firmas
- Botón para **imprimir o guardar en PDF**

## Uso

1. Abre `index.html` en tu navegador.
2. Selecciona la categoría oficial (A, B, C o D) para autocompletar grados y temática.
3. Completa o ajusta los datos del certificado.
4. Marca o desmarca los elementos que quieres incluir (categoría, grados, temática, logo, etc.).
5. Sube el logo del colegio (si está habilitado).
6. Haz clic en **Imprimir / Guardar PDF**.

## Categorías configuradas

- **A**: Pre kinder y Kinder - Hadas (Adas)
- **B**: Primero, segundo y tercero - Mariposas
- **C**: Cuarto, quinto y sexto primaria - Flores
- **D**: Primero, segundo, tercero básico y cuarto y quinto bachillerato - Libre (hadas, mariposas y flores)
